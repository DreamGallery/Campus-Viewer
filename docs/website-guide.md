# 使用说明

## 剧情浏览

按角色、主线、辅助卡、活动和其他剧情浏览章节，支持搜索、分类筛选及排序。文本更新页收录最近两周的更新。

## 资源版本与下载

点击页面顶部「学园剧情档案」旁的资源版本号，可展开下载列表，下载最近保留的 **5 份增量资源包**。
资源包按游戏资源的 revision 版本生成，包含该版本新增或变更的游戏资源，并按更新脚本进行解包、图片拉伸等处理。

## 翻译协作

使用 GitHub 登录，并拥有协作仓库的写权限后，即可查看任务。译文、草稿和任务记录保存在 GitHub 协作仓库中。

### 查找与认领任务

- 可以搜索剧情资源名，按剧情分类、任务状态筛选，并切换排序。
- 「我的任务」显示自己参与的任务；完成统计展示个人及成员的翻译、校对数量。
- 点击「认领翻译」或「认领校对」进入多选模式，选中任务后边框变色，再点击确认认领。也可以选择本页或全部筛选结果中的待认领任务。
- 普通浏览模式下，点击任务卡片进入章节编辑页。

### 编辑与校对

1. 进入章节后，点击「连接协作任务」。连接只读取任务信息，不会自动替换翻译框中的文字。
2. 选择翻译或校对工序，认领任务；已完成的工序可点击「修订」。切换工序无需重新连接。
3. 按需载入机器译文、翻译稿、校对稿或 GitHub 草稿。载入远端译文会替换编辑框中的现有译文。
4. 编辑完成后，在文本底部保存 GitHub 草稿，或提交完成。

编辑器支持：

- 原文与译文对照、人物头像，以及已匹配台词的语音播放。
- 搜索台词、只看未翻译文本。
- 直接回车换行，导出时转换为游戏使用的 `\n`。
- 使用「强调点」「注音」按钮插入特殊格式。
- 完成提交前检查空译文及标签格式；单行超过 **21 字** 时提醒确认换行。

### 草稿与完成提交

| 操作 | 作用 |
| --- | --- |
| 浏览器自动保存 | 保存当前浏览器中的编辑内容，不会自动上传 GitHub。 |
| 保存 GitHub 草稿 | 上传当前工序的草稿，不修改正式稿，也不标记任务完成。 |
| 恢复远端草稿 | 将 GitHub 草稿载入编辑框。草稿基于旧版正式稿时，需要先下载核对。 |
| 完成翻译／校对 | 保存正式稿及版本记录，清理对应远端草稿，并将对应工序标记为完成。 |

远端草稿按章节和工序保存，不是每位用户独立一份。正式提交会检查版本，避免旧编辑内容覆盖已更新的正式稿。

CSV 保留原有「译者」一行。完成翻译时署名为 `翻译：XXXX`；完成校对时保留原译者，写成 `翻译：XXXX；校对：XXXX`。提交者优先使用 `users.json` 匹配到的个人显示名，未匹配时使用 GitHub 用户名。

### 导入与导出

- 章节页可导入 CSV，也可将当前编辑内容导出为 CSV 或 TXT。
- 译文 TXT 导出将翻译迁移到游戏原脚本中，并按[人名字典](https://github.com/chihya72/Gakumas-Auto-Translate/blob/master/name_dictionary.json)替换发言人名称；未翻译的台词、字典中没有的姓名保留原文。
- 协作首页点击「选择导出」后，可以多选任务，选择翻译稿、校对稿或机器译文等版本，批量下载 CSV／TXT；多个文件打包为 ZIP。
- 批量导出读取所选远端版本，不包含尚未上传的浏览器草稿。
